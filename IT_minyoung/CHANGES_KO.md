# 수정 내역

요청 내용을 기준으로 인증, 방, 여행 날짜 조율, 개인 일정, 홈, 기록, 프로필, 친구, 알림, 개인정보/계정 기능을 하나의 Supabase 데이터 모델로 연결했습니다.

중요한 제약은 UI뿐 아니라 Supabase 함수와 트리거에도 적용했습니다. 방 생성/참여/나가기/방장 위임, 친구 요청/수락, 방 초대/수락, 일정 후보 계산/동의/투표/확정, 앨범 삭제는 RPC로 묶었고, 확정된 여행 날짜는 트리거로 변경을 막습니다. 기록 사진은 공개 URL이 아닌 보호된 Storage 버킷과 시간 제한 서명 URL을 사용합니다.

실제 푸시와 이메일 발송은 외부 서비스 자격증명이 필요해 자동 연결하지 않았습니다. 자세한 적용 순서는 `SETUP_GUIDE_KO.md`를 따르세요.
